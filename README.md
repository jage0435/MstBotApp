# 彈珠自動拖曳 Android App v0.4

按下開始後，自動從螢幕中心往右上或左上拖曳（怪物彈珠的彈射），每隔幾秒重複一次。
關卡打完、畫面上方出現「OK」時會自動停止。

> ⚠ 自動化操作違反遊戲使用條款，可能被停權。請自行評估，建議先用小號測試。

- **需求**：Android 11 以上的手機
- **原理**：用「無障礙服務」模擬拖曳，並截圖辨識畫面上方有沒有「OK」。截圖只在手機上辨識，不會上傳；不改遊戲，也不需要 root。

## 一、編譯與安裝

1. 用 Android Studio **File → Open** 這個資料夾，等 Gradle Sync 跑完。
2. 手機開「USB 偵錯」接上電腦，按 ▶ Run；或 **Build → Build APK(s)**，APK 在 `app/build/outputs/apk/debug/app-debug.apk`。

## 二、第一次設定

1. 打開 App，按底部的「開啟無障礙服務」→ 開啟「彈珠自動拖曳 自動操作」。
   - Android 13 以上若開關是灰色：設定 → 應用程式 → 彈珠自動拖曳 → ⋮ →「允許受限制的設定」，再回來開。
2. 回到 App，狀態變成「已就緒」，螢幕上會出現浮動面板。

## 三、設定頁

| 區塊 | 設定 | 預設 |
|---|---|---|
| 方向 | 右上／左上／交替／隨機，上方有預覽圖 | 右上 |
| 方向 | 拖曳長度（螢幕寬的比例） | 30% |
| 拖曳時間 | 按住時間（建議 480～500 ms，彈不出去再調長到 600～800） | 500 ms |
| 拖曳時間 | 隨機誤差（每次 ± 隨機，避免太規律） | ±30 ms |
| 重複 | 間隔秒數（0 = 只滑一次） | 6 秒 |
| 關卡結束自動停止 | 出現 OK 就停止 | 開 |
| 關卡結束自動停止 | 偵測範圍（只看畫面上方這個比例） | 60% |

- 設定改了立刻生效，不用按儲存；「恢復預設值」可以全部改回來。
- 「關閉 App」會停止滑動、移除浮動面板並關掉無障礙服務；下次使用要再到無障礙設定開啟。

## 四、使用

1. 進遊戲戰鬥畫面，按浮動面板的綠色 ▶ 開始，紅色 ■ 停止；≡ 回到設定頁。
2. 面板拖曳左邊的握把移動，放開會自動貼齊左右邊。請放在不會擋到螢幕中心的位置。
3. 打完關卡出現 OK 時會自動停止，面板顯示「關卡結束，已停止」。

## 五、校正「自動停止」

戰鬥中隊友的 SS 準備好時，**下方隊伍欄也會出現「OK」**，所以只看畫面上方。建議第一次使用時這樣檢查：

1. 在**通關畫面**：設定頁按「測試偵測（3 秒後截圖）」，3 秒內切回遊戲 → 應該顯示「有找到 OK」。
2. 在**戰鬥中、有 SS 準備好時**：再測一次 → 應該顯示「沒有找到 OK」。
3. 如果戰鬥中也找到了，把「偵測範圍」調小；通關畫面找不到，就調大。

測試時會存一張標記圖（黃線 = 偵測範圍下緣、綠框 = 找到的 OK），接電腦可以拿出來看：

```bash
adb pull /sdcard/Android/data/com.mstbot/files/detect_test.png
```
